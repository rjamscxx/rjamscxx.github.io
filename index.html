Singel IPMS

Inventory and procurement system · Singel Group of Companies, founded 1987

Tracks what each project needs, what was bought, what arrived, where it sits and where it went. Every step is its own numbered record, so any figure on any screen traces back to the documents behind it.

  • The system calculates stock from movement records instead of storing totals, so figures can't drift.
  • Corrections void and reverse the original record, and the database blocks edits and deletes.
  • Whoever raises a document can't approve or receive it. The server and row-level security both check this.
